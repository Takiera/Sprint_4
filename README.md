# Яндекс Самокат — UI-тестирование

**Java · Selenium · JUnit 4 · Page Object**

Учебный проект Яндекс Практикума.

Проверка сценариев сервиса аренды самокатов: получение ответа в FAQ и оформление заказа.

## Подход к тестированию

- **Параметризация:** сценарии FAQ и заказа используют наборы входных данных.
- **Пользовательский путь:** заказ проверяется от точки входа до сообщения об оформлении.
- **Оракул проверки:** для FAQ задан ожидаемый текст, для заказа — ожидаемое сообщение об успехе.
- **Page Object:** формы и действия страниц отделены от assertions.
- **Настройка браузера:** реализован выбор Chrome или Firefox через системное свойство.
- **Жизненный цикл драйвера:** создание и закрытие браузера вынесены в общую инфраструктуру.

## Технологии

- Java;
- Selenium WebDriver;
- JUnit 4, параметризованные проверки;
- WebDriverManager;
- Page Object Model.

## Что проверяется

### FAQ

Для восьми вопросов проверяются раскрытие соответствующего пункта и отображение ожидаемого текста ответа.

### Оформление заказа

Два набора данных описывают оформление заказа:

- через верхнюю кнопку «Заказать»;
- через нижнюю кнопку «Заказать».

Сценарии включают заполнение данных пользователя, выбор метро, даты, срока аренды и цвета самоката, подтверждение заказа и проверку сообщения об оформлении.

## Структура

```text
src/main/java/FactoryDriver.java       # создание и закрытие драйвера
src/main/java/pageobjects/             # объекты страниц
src/test/java/                        # FAQ и заказ
pom.xml                               # зависимости
```

## Запуск

Скачайте исходники `main`, распакуйте их и откройте терминал в каталоге с `pom.xml`.

Chrome используется по умолчанию:

```bash
mvn test
```

Для Firefox:

```bash
mvn test -Dbrowser=firefox
```
